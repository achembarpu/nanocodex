# Install TypeScript and JavaScript

Install the core package for Node.js 22.13 or newer, browser Workers, or a
server isolate:

```sh
npm install nanocodex
```

Import from the host you actually run:

```js
import { Agent, Actions, Transport, Workspace } from "nanocodex/node";
```

```js
import { Agent, Subagents, Transport, Workspace } from "nanocodex/browser";
```

Both entrypoints expose the same Rust-owned session behavior. Host-specific
exports supply WebSocket and workspace adapters; generated wasm-bindgen handles
remain package internals.

## Know what is published

The registry package contains the core root, Node, browser, and WASM entrypoints.
The React, artifact, TUI, and terminal companion packages currently ship from
repository source. Pin a repository revision when adopting a source-distributed
package so its bindings and generated WASM stay coherent.

The browser tools composition also uses the package Vite adapter in both the
page and nested Worker graphs:

```js
import { nanocodexTools } from "nanocodex/tools/vite";
import { defineConfig } from "vite";

export default defineConfig({
  plugins: [nanocodexTools()],
  worker: { format: "es", plugins: () => [nanocodexTools()] },
});
```

This adapter keeps the browser shell's SSH compatibility boundary consistent.
It does not add another agent runtime.

## Start from a complete consumer

Use the [Node example](https://github.com/gakonst/nanocodex/tree/master/examples/node)
for a local guarded workspace. Use the
[React/Vite example](https://github.com/gakonst/nanocodex/tree/master/examples/react-vite)
for a module Worker, or the
[one-file browser example](https://github.com/gakonst/nanocodex/tree/master/examples/browser-cdn)
when you want to inspect the smallest browser host.
