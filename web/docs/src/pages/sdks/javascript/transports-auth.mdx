# TypeScript transports and authentication

Pass one explicit immutable `Transport` to `Agent.create`. The constructor says
who owns authentication and socket setup; it does not select a different agent
implementation.

```js
Transport.openAi({ apiKey, websocketUrl });
Transport.chatGpt({ subscription });
Transport.mpp({ session: paymentSession });
```

`openAi` is the direct API-key path. `chatGpt` accepts a caller-owned managed
ChatGPT subscription. `mpp` accepts a caller-owned paid session with a WebSocket
method. All three route the deliberately supported OpenAI Responses agent
family; Nanocodex is not a provider abstraction.

## Keep browser credentials behind a host

The browser entrypoint also provides a host-managed transport for an application
Worker, Durable Object, or proxy that rotates credentials:

```js
const transport = Transport.hostManaged({
  websocketUrl: "/api/responses",
  createWebSocket: (endpoint) => new WebSocket(endpoint),
});
```

The browser sees only the application endpoint. The host owns credentials,
authorization, rate limits, and tenant routing. A host-managed socket must still
preserve the Responses WebSocket contract expected by the Rust driver.

Do not place API keys or bearer credentials in URLs, local storage, React state,
or generated WASM configuration. Treat any durable session identifier that
authorizes reads or writes as an application capability and scope it accordingly.

## Keep routing separate from agent policy

Transport configuration belongs beside credential ownership. Instructions,
thinking, workspace, tools, and execution environment belong on `Agent.create`.
This separation lets a deployment replace or refresh credentials without
inventing a second conversation state machine.

See the [Node example](https://github.com/gakonst/nanocodex/tree/master/examples/node),
[Cloudflare Durable Object](https://github.com/gakonst/nanocodex/tree/master/examples/cloudflare-workers),
and [Vercel Workflow actor](https://github.com/gakonst/nanocodex/tree/master/examples/vercel-workflows)
for complete credential and socket owners.
